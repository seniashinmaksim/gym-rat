# Russian glossary (Part 6, F.10)

Every text in the app is written as a pair `L('English', 'Русский')` (see `src/i18n/index.ts`).
Use these terms consistently. Style: short, informal-polite "вы" in lower case, imperative for
buttons ("Записать подход"), no exclamation marks, no praise words. Units: кг, см, с, мин, ч.
Exercise and muscle names come from the library (`name.ru`).
